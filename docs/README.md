# Документация Otklikator

Otklikator — платформа автопоиска вакансий и (на следующем этапе) автооткликов. Код — TypeScript на Cloudflare Workers,
этот каталог описывает, как он устроен и как его вести.

| Документ | Что внутри |
|---|---|
| [product.md](product.md) | Идея продукта, для кого он, путь пользователя от регистрации до подбора вакансий |
| [architecture.md](architecture.md) | Компоненты, маршруты, схема D1, CV и анкета, Stripe, конвейер вакансий на Cron, скоринг |
| [feeds.md](feeds.md) | Источники вакансий и политика опроса: расписание, паузы на 429/403, письма о сбоях |
| [operations.md](operations.md) | Среды (staging и prod), секреты, деплой, миграции, runbook |
| [roadmap.md](roadmap.md) | Что сделано (PR 1–5), этап 4 и открытые решения |

План MVP (живой документ): https://claude.ai/artifact/AswwCPj4ePRCJJLEBDYYYg
